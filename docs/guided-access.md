# Accès guidé (Guided Access)

Kidzy locks the player inside the app: 4 taps in the top-left corner are the only way back to the
library, and the parent area needs the PIN. What an app cannot do on iOS is block the Home swipe
or the side button. Apple's **Guided Access** does exactly that.

Set it up once on the phone the kids use:

1. Réglages → Accessibilité → Accès guidé → activer, puis « Réglages du code » → choisir un code
   (and Face ID if wanted).
2. Open Kidzy, then **triple-click the side button**. Tap « Démarrer » (top right).
3. The phone stays in Kidzy. To leave: triple-click again, enter the code, « Fin ».

Options worth setting in the Guided Access screen (« Options », bottom left): disable the volume
buttons if the kid keeps changing it; keep « Toucher » on; a time limit here is optional since
Kidzy has its own.
